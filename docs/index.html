"오늘 캠페인이 잘 되고 있나?" — 날짜 범위를 설정하면 발송·반응·전환·매출 흐름을 한눈에 파악합니다.

📊 KPI 요약 카드 (상단 6개)
푸시 수신동의 · DAU · MAU · Revenue · 전체 발송/노출 · 평균 CTR · 유저당 메시지 수를 한 화면에 요약합니다. 각 카드 우측 상단에 WoW 변화율이 표시되고, 카드에 마우스를 올리면 최근 14일 미니 트렌드 차트가 팝업으로 나타납니다. 💡 유저당 메시지 수가 급격히 오르면 과발송 신호 — 수신동의 감소와 함께 보세요.
📈 일별 발송/반응 콤보차트
막대(발송/노출량, 오픈/클릭 수)와 선(CTR, 구매 CVR)을 하나의 축에 겹쳐 표시합니다. 볼륨(막대)과 반응률(선)을 동시에 보기 때문에, 발송량이 늘어나는 날 CTR이 함께 내려가면 타겟팅이 희석되고 있다는 신호입니다. 💡 발송량 급등 + CTR 하락이 동시에 보이면 소재·세그먼트 점검이 먼저입니다.
🏆 캠페인 성과 Top 10
드롭다운에서 발송/노출량 · 오픈/클릭율 · 구매 CVR · Revenue · AOV 중 정렬 기준을 선택하면 상위 10개 캠페인을 가로 막대 차트로 즉시 비교합니다. Campaign Depth 1 기준으로 그루핑됩니다. 💡 Revenue Top과 CTR Top이 다를 때 — CTR이 높아도 AOV가 낮은 캠페인은 매출 기여가 제한적입니다.
🔽 전환 퍼널 (Full-Funnel)
각 스텝을 드롭다운으로 직접 조합해 2~4단계 퍼널을 구성합니다. 선택 가능한 스텝: DAU · 프로모션 리스트 조회 · 상품 상세 조회 · 장바구니 조회 · 좋아요 · 구매 건수 · 첫 구매 등. 단계 사이에 이탈률(%)이 자동 계산되어 표시됩니다. 💡 상품 상세 → 장바구니 이탈이 크면 상세페이지 설득력, 장바구니 → 구매 이탈이 크면 결제 UX 또는 가격 문제입니다.
📋 커스텀 이벤트 일별 추이
체크박스로 이벤트(첫 구매 · 좋아요 · 장바구니 · 프로모션 조회 등)를 선택하면 복수 라인을 한 차트에 겹쳐서 비교합니다. 캠페인 발송일 전후로 특정 이벤트가 얼마나 반응하는지 상관관계를 시각으로 잡을 수 있습니다. 💡 발송 다음 날 like_product 급등 → 소재가 상품 발견에 기여했다는 신호. 구매로는 이어지지 않으면 가격·재고 점검.
📋 비즈니스 지표 기간 비교
Revenue · DAU · MAU · AOV · ARPU · ARPPU · 구매 건수 · 활성 대비 구매 비중을 테이블로 나열하고, 각 지표마다 WoW와 MoM / YoY (토글 전환) 변화율을 나란히 표시합니다. 지표 옆 30일 스파크라인으로 추세 방향도 한눈에 파악 가능합니다. 💡 Revenue ▲ + ARPU ▼ 조합이면 신규 유저 유입으로 볼륨은 늘었지만 1인당 기여는 낮아진 것. CRM 리텐션 전략을 점검할 타이밍입니다.
📬 수신동의 카드
푸시 · SMS · 카카오 수신 동의자 수를 채널별 카드로 표시합니다 (누적 기준). 수신동의 수는 CRM 캠페인이 도달할 수 있는 유효 모수이므로, 발송량 대비 수신동의 수가 계속 줄면 도달 효율이 하락하는 것입니다. 카드에 마우스를 올리면 최근 14일 일별 추이를 확인할 수 있습니다. 💡 푸시 수신동의가 꾸준히 감소하면 앱 내 옵트인 프롬프트 노출 시점·조건을 재검토하세요.
📊 채널별 성과 비교
푸시·인앱·SMS·카카오 등 채널 기준으로 그루핑한 성과 테이블. 발송/노출 · CTR · CVR · Revenue · 발송당 Revenue 5개 지표를 한 줄에서 비교합니다. 발송/노출 컬럼에는 비율 바가 표시되어 채널 간 볼륨 차이를 시각적으로 파악할 수 있습니다. CTR은 10% 이상이면 초록, 5% 미만이면 빨강으로 표시되어 채널 반응률 이상값을 빠르게 포착합니다. 💡 발송당 Revenue가 높은 채널이 ROI 효율이 좋은 채널 — 예산·소재 우선순위 결정 시 기준 지표로 활용하세요.
💰 Revenue · AOV 추이 / 발송당 Revenue 추이
두 개의 콤보차트가 나란히 배치됩니다. Revenue · AOV 차트는 일별 매출(막대)과 평균 주문금액(선)을 겹쳐 보여줍니다 — Revenue가 늘어나는데 AOV가 내려가면 저단가 상품 중심 구매 증가 신호로, 할인 전략 효과를 점검해야 합니다. 발송당 Revenue 차트는 메시지 1건이 만들어낸 매출과 예상 Reward(CTR × CVR)를 함께 표시해 채널·캠페인 ROI를 비교하는 데 사용합니다. 💡 발송당 Revenue가 높은 기간과 캠페인 타입을 교차 확인하면 예산 집중 구간을 찾을 수 있습니다.

📌 요약 배너 (Summary Banner)
필터 기간 전체를 합산한 핵심 지표 4개 — 유저 CVR · 주문 CVR · Revenue · AOV를 상단 배너에서 즉시 확인합니다. 필터(날짜 · Source Alias · Message Type 등)를 바꾸면 배너 수치도 실시간으로 바뀌므로, 특정 캠페인·채널의 기여 규모를 빠르게 스캔할 때 사용합니다.
🛒 구매 지표 탭
CRM 메시지를 수신한 유저 기준으로 유저 CVR · 주문 CVR · 구매 건수 · Revenue · AOV · ARPPU · 구매 빈도 · 주문당 아이템 수 · 유저당 아이템 수 9가지 지표를 KPI 카드 + 일별 트렌드 차트로 표시합니다. 트렌드 차트에는 WoW · MoM 비교 라인이 함께 그려져 같은 기간 전주·전월 흐름과 즉시 대조할 수 있습니다. 💡 구매 빈도(purchase_count ÷ purchase_user)가 오른다면 리텐션 캠페인이 반복 구매를 유도하고 있는 것입니다.
📈 기타 이벤트 탭
구매 외 커스텀 이벤트(장바구니 담기 · 좋아요 · 프로모션 조회 등)를 드롭다운으로 선택하면 해당 이벤트의 CVR(수신자 대비 전환 비율)과 일별 발생 수 트렌드를 표시합니다. 이벤트 목록은 ATT_DATA 시트에 존재하는 항목에서 자동 추출됩니다. 💡 구매 CVR은 낮은데 장바구니 CVR이 높다면 — 메시지가 탐색을 유도하지만 마지막 결제 전환에서 이탈하는 것. 리마인더 캠페인이나 혜택 강화가 유효합니다.
TAB 03 캠페인 운영 현황 운영 체크

"지금 어떤 캠페인이 살아있나?" — Braze에서 실시간으로 라이브 캠페인 목록, 트리거 구조, 예약 발송 일정을 확인합니다. 데이터는 3분 캐시로 관리됩니다.

📡 발송량 & 반응 트렌드 (최근 30일)
Google Sheets 데이터 기준으로 최근 30일간 일별 Sent/Impression(막대)과 Open/Click(선)을 겹쳐 표시합니다. 운영 현황 탭의 도입부 차트로, 전체 CRM 발송 볼륨과 반응 흐름을 빠르게 스캔합니다. 💡 특정 날 막대가 급등했다면 그날 일괄 발송 캠페인이 실행된 것 — 아래 라이브 캠페인 테이블에서 해당 날짜 캠페인을 교차 확인하세요.
⚡ 라이브 캠페인 테이블
Braze API에서 실시간(3분 캐시)으로 불러온 활성 캠페인 전체 목록입니다. 상단 채널 탭(전체 / 푸시 / 이메일 / SMS / 카카오 / 인앱)으로 채널 단위 필터가 가능합니다. 각 캠페인 행 오른쪽 링크 아이콘을 클릭하면 Braze 대시보드로 직접 이동합니다. 💡 목록이 오래된 것 같으면 설정 탭 → [저장]을 눌러 캐시를 초기화하세요.
🔗 Action-Based 트리거 이벤트 현황
유저 행동(장바구니 담기 · 구매 완료 · 특정 이벤트 등)이 어떤 캠페인을 발동하는지 트리거 이벤트별 카드로 정리합니다. Braze 이벤트명이 영문 코드로 나올 경우 탭 우측 상단 편집 버튼을 클릭해 한글 레이블을 직접 지정할 수 있으며, 설정은 저장되어 이후에도 유지됩니다. 💡 같은 트리거에 캠페인이 여러 개 묶여있으면 동일 유저에게 중복 발송될 수 있습니다 — 우선순위와 발송 간격을 점검하세요.
📅 Scheduled 캠페인 타임라인
기준 날짜 기준 -3일 ~ +7일 범위의 예약 발송을 시간순으로 나열합니다. 미래 시점은 Braze /messages/scheduled_broadcasts API의 next_send_time을, 과거는 first_sent 값을 사용합니다. 같은 시간대에 여러 캠페인이 집중되어 있으면 발송 충돌 여부를 미리 확인할 수 있습니다. 💡 주요 이벤트·프로모션 전날 타임라인을 미리 확인해 중복 발송이나 발송 공백이 없는지 점검하는 용도로 활용하세요.
TAB 04 설정 초기 세팅

대시보드에 연결할 데이터 소스(Google Sheets, Braze)와 차트 색상을 관리합니다. 처음 프로젝트를 만들 때 한 번 설정하고, 키 변경 시에만 다시 입력합니다.

🏷️ 프로젝트 이름
화면 상단에 표시되는 프로젝트 명칭. 고객사나 브랜드명으로 설정하세요.
⚡ Braze 연결
REST Endpoint — Braze 대시보드 URL에서 확인 (예: https://rest.iad-07.braze.com)

API Key — Braze 콘솔 → Developer Console → REST API Key. 필요 권한: campaigns.list, campaigns.details, messages.schedule.broadcast

이미 설정된 키가 있으면 "설정됨" 표시. 변경할 때만 새 키를 입력하세요.
📊 Google Sheets 연결
Spreadsheet ID — 시트 URL의 /d/…/ 부분

Google API Key — Google Cloud Console → API & Services → Credentials

키 입력 후 [시트 목록 불러오기] 버튼을 클릭하면 스프레드시트의 시트 목록이 드롭다운으로 나타납니다. martinee_union · daily_kpi · ATT_DATA 각각에 해당하는 시트를 선택·매핑하세요.
🎨 차트 색상
차트에 사용할 색상 팔레트를 최대 8개까지 커스텀 가능. 색상 박스를 클릭해 색상 피커로 변경합니다.
💾 저장
모든 설정 변경 후 반드시 [저장] 버튼을 눌러야 반영됩니다. 저장 즉시 데이터 캐시가 초기화되어 최신 데이터를 다시 불러옵니다.

설정 가이드

처음 세팅하는 방법

1
프로젝트 이름을 입력하세요. 화면 상단에 표시되는 이름입니다.
2
Braze REST Endpoint를 입력하세요. Braze 대시보드 URL에서 확인할 수 있습니다 (예: rest.iad-07.braze.com).
3
Braze API Key를 입력하세요. Braze 콘솔 → Developer Console → REST API Keys에서 생성. 필요 권한: campaigns.list, campaigns.details, messages.schedule.broadcast.
4
Google Spreadsheet ID를 입력하세요. 시트 URL에서 /d/[여기]/ 부분입니다.
5
Google API Key를 입력하세요. Google Cloud Console → API & Services → Credentials에서 생성.
6
[시트 목록 불러오기] 버튼을 클릭해 스프레드시트의 시트 목록을 가져옵니다. martinee_union · daily_kpi · ATT_DATA 각각에 해당하는 시트 이름을 드롭다운에서 선택하세요.
7
[저장] 버튼을 클릭하면 완료. 저장 즉시 데이터가 새로 로드됩니다.

자주 묻는 질문

API Key가 이미 설정됐는데 또 입력해야 하나요?

아니요. "설정됨"으로 표시된 경우 변경 시에만 새 키를 입력하면 됩니다. 비워두면 기존 키가 유지됩니다.

Braze 데이터가 안 불러와져요

API Key 권한이 부족한 경우가 많습니다. campaigns.list, campaigns.details, messages.schedule.broadcast 3가지를 확인하세요.

시트 데이터가 오래된 것 같아요

설정 → [저장]을 누르면 캐시가 초기화되어 최신 데이터를 다시 불러옵니다.

트리거 이벤트 이름이 영문 코드로 나와요

운영 현황 탭 → Action-Based 트리거 카드 → 우측 상단 편집을 클릭해 한글 레이블로 직접 지정하면 됩니다.
